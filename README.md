# Pedra, Papel e Tesoura 🪨📄✂️

Este projeto é uma implementação simples do jogo **Pedra, Papel e Tesoura** usando **JavaScript puro**, rodando no console do navegador.

O objetivo é praticar conceitos básicos de programação como:
- Funções
- Condicionais
- Laços de repetição
- Variáveis
- Lógica de programação

---

## 📌 Como funciona o jogo

- O jogo acontece em **5 rodadas**
- Em cada rodada:
  - O jogador escolhe entre **pedra**, **papel** ou **tesoura** através de um `prompt`
  - O computador escolhe aleatoriamente
- O placar é atualizado a cada rodada
- Ao final das 5 rodadas, o vencedor é anunciado no console

---

## 🕹️ Regras

- Pedra vence Tesoura  
- Tesoura vence Papel  
- Papel vence Pedra  
- Se ambos escolherem a mesma opção, ocorre empate  

---

## 🚀 Como executar

1. Abra o arquivo JavaScript no navegador (via `<script>` em um HTML)
2. Abra o **Console do navegador** (F12)
3. O jogo começará automaticamente
4. Digite sua escolha quando o `prompt` aparecer

---

## 🛠️ Tecnologias utilizadas

- JavaScript (ES6)
- Console do navegador
